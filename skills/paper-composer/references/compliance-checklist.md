# 成稿合规检查清单

## 使用方式

在骨架确认、逐节成稿和最终组装后分别检查。最终结果写入 `reports/compliance.md`，每项标注 `pass`、`fail`、`n/a` 或 `unknown`，并附证据路径或说明。

## 一、模板与结构

- [ ] 使用机构模板的文档类、页面尺寸、页边距和分栏。
- [ ] 章节层级、编号和标题大小写与模板一致。
- [ ] 摘要、关键词、正文、致谢、参考文献、附录顺序正确。
- [ ] 页眉页脚、页码、水印或盲审标识未被破坏。
- [ ] 模板占位文本已替换或列入缺口。
- [ ] 模板原件未被修改；所有改动位于工作区副本。

## 二、内容与证据

- [ ] 每个关键论点绑定至少一个 `verified` 证据 ID。
- [ ] 正文数字与 `evidence/manifest.json` 一致。
- [ ] 图表均已登记，caption、编号和正文引用一致。
- [ ] 外部图表已标注出处与许可，未冒充本地结果。
- [ ] 引用均可核验；没有虚构、错配或未读文献。
- [ ] 局限性、失败案例和证据边界已如实说明。

## 三、篇幅与语言

- [ ] 总页数或字数符合投稿要求。
- [ ] 各章节字数在预算内，无头重脚轻。
- [ ] 摘要不含未在正文出现的结论或数字。
- [ ] 术语、缩写、单位全文一致；缩写首次出现有全称。
- [ ] 语言风格与目标读者匹配，无口语化占位和草稿痕迹。

## 四、投稿合规

- [ ] 匿名要求已满足：作者、单位、基金、致谢和文件元数据均已处理。
- [ ] 作者顺序、单位、通讯作者和贡献声明已由用户确认。
- [ ] 基金、利益冲突、伦理审批、数据可用性、代码可用性声明齐全。
- [ ] 补充材料、数据集和代码链接可访问或已打包。
- [ ] 文件命名、格式和大小符合投稿系统要求。
- [ ] 图表分辨率、字体嵌入和颜色可读性符合要求。

## 五、构建与校验

- [ ] LaTeX 使用模板指定引擎成功编译，无未定义引用和缺图。
- [ ] Word 文档保留模板样式，无样式丢失或编号错乱。
- [ ] 运行 `verify_manuscript.py --strict` 无阻断错误。
- [ ] 生成的 PDF/DOCX 已人工打开检查分页、图表位置和特殊字符。
- [ ] 输出文件与源文件版本一致，构建可复现。
